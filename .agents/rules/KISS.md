# KISS Principle (Keep It Simple, Stupid)

> **Mandatory Policy:** Simplicity is a core architectural goal. Always choose the simplest working solution over clever or unnecessarily complex abstractions.

## Core Directives

* **Avoid Overengineering:** Do not add premature abstractions, unnecessary design patterns, or speculative features before they are explicitly needed.
* **Readable Over Clever:** Write clear, self-explanatory code instead of dense, convoluted "one-liners" or obscure language tricks.
* **Minimal Scope:** Solve only the current problem directly. Keep functions, modules, and workflows compact, focused, and easy to maintain.
* **Prune Redundancy:** Remove dead code, redundant boilerplate, and unnecessary dependencies.
